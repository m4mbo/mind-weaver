
# Mind Weaver

You wake up as a mage, trapped deep within the confines of a dungeon ruled by goblins. Luckily, your butterfly companion has managed to set you free. It is now up to your imagination and your ability to control minds to help you escape! For more information, see [page](https://mbaranr.github.io/projects/mind_weaver/).

## How to Play
Download the latest version (jar file) from the [Releases](https://github.com/mbaranr/mind-weaver/releases) section or alternatively build from source. Also available on [Steam](https://store.steampowered.com/app/3158220/Mind_Weaver/)!

### Build and Run

Unix based systems:

```
$ cd scripts
$ ./run.sh
```
