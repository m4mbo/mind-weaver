
# Mind Weaver

A 2D puzzle platformer built around line-of-sight control. For more information, see [page](https://mbaranr.github.io/projects/mind_weaver/).

## How to Play
Download the latest version from [Releases](https://github.com/mbaranr/mind-weaver/releases) or alternatively build from source (see below). Also available on [Steam](https://store.steampowered.com/app/3158220/Mind_Weaver/)!

### Build and Run

Unix based systems:

```
$ cd scripts
$ ./run.sh
```
